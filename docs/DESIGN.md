# 睡眠随记 2.1 界面规范

场景：单人使用安卓手机，按病人／日期录入五种量表，查看得分并导出。

采用 ui-ux-pro-max 的原生移动端规范，结合 better-layout 的分组与适配、better-ui 的一致状态与表面处理。设计系统检索两次返回的首页营销模式不符合数据录入场景，未采用该模式或外部字体；布局由现有业务流程决定，原生Java View实现，不更换技术栈。

## 固定设计选择

- 浅色临床工具界面：背景 #F5F7F9；主文字 #192B37；次文字 #566874；主色 #0D736C；提醒 #934418；控件边界 #788A94。系统深色时继续使用明确定义的浅色主题，禁用强制反色。
- 系统中文字体，字号按sp随系统缩放。标题24sp，条目16～17sp，辅助信息12～13sp。常用间距4／8／12／16dp。
- 原生按钮与选项最小48dp触摸高度；有描边、选中状态和原生水波反馈。数字评分在显示选中色之外还显示“已选择：N分”，并保留RadioButton语义。
- 首页仅一个主操作“添加病人”；底部固定病人、统计、备份、更多四入口。图标为本地矢量绘制。
- 日得分表在360dp默认字号下显示日期与五量表；320dp或大字体时提供滚动提示及左右按钮。整行是进入当天记录的48dp触摸区域。
- 长姓名／编号可通过点标题或病人日期区域查看全文。大字体下动作组改为纵向；所有字号和方向下表单完成按钮均位于滚动内容末尾，先完整填写再计分。
- 日期与病人信息合并，量表说明放入明确入口；各量表的回顾范围仍在页面中展示，不改写题目和评分。
- NRS使用会自动换行的原生单选数字网格；每次选择仍立即走原有事务保存。不得通过防抖延迟数据落库来优化界面。

## 验证方式

雷电Android 14实例 emulator-5554，默认360×640dp；额外检查320dp宽、640×360dp横屏、2倍系统字号、系统深色及关闭动画；检查键盘显示时焦点字段可见。截图只用虚拟测试档案。

未将浏览器专用CSS、网页RTL镜像、营销模板、在线字体或外部图片引入原生离线应用。未声称通过完整TalkBack人工审查或临床量表验证。
