# 0.0.2 更新（2026-11-17）

- HAMD各题可留空，新增“保存并结束（可缺项）”及清除此题按钮。缺项按未计分草稿保存，无总分，不计入均值；完整评定仍可计分。
- 自定义睡眠NRS：0分睡眠极好，10分整夜无法入眠，采用昨夜窗口，与疼痛NRS分开统计、导出。
- 新建PSQI补全近一个月提示、第5题问题、第7题药物说明、第8、9题及选填同伴观察。补充观察不计分。旧记录保留原第8、9题含义，新建记录textVersion=2，条目导出可见。
- 每日得分、Excel增加睡眠NRS列，横向滑动查看。

沿用原签名，versionCode 9，覆盖安装，不要卸载。新备份含新量表及扩展字段，应使用0.0.2或后续兼容版本恢复。本版支持旧备份。
